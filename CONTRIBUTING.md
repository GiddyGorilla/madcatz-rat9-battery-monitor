# Contributing

Thanks for helping improve the R.A.T. 9 battery monitor.

## Before opening an issue

- Run `RAT9BatteryProbe.exe`.
- Confirm the SmartTechnology version and Windows version.
- Check the troubleshooting guide.
- Search existing issues for the same device or driver behavior.

## Pull requests

1. Keep changes focused and explain the user-visible behavior.
2. Build locally with `pwsh -ExecutionPolicy Bypass -File .\build.ps1`.
3. Do not commit `dist/`, credentials, tokens, or proprietary Mad Catz DLLs.
4. Include screenshots for UI changes.
5. Preserve Windows 10 compatibility unless a maintainer agrees otherwise.
