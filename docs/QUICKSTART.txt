R.A.T. 9 + EWEADN V102 PRO BATTERY MONITOR
==========================================

QUICK START

1. Extract the release ZIP to a permanent folder.
2. Start RAT9BatteryTray.exe.
3. Left-click the percentage icon in the system tray.
4. The panel shows the R.A.T. 9 and V102 Pro side by side.
5. Click outside the panel to close it, or pin it from the tray menu.

The tray icon shows the lowest connected battery. Charging, disconnecting,
and the learned time range are shown in the tooltip and detail panel.

R.A.T. 9 BATTERY SWAPS

The R.A.T. 9 reader runs in an isolated worker. If a driver read hangs, the
worker is released and restarted automatically. The tray menu also provides:

- "Batteribyte: pausa läsaren"
- "Återanslut musen"
- "Återställ musanslutningen (admin)" when the recovery task is installed

V102 BATTERY

The V102 Pro is read over the standard HID interface exposed by its 2.4 GHz
dongle. Run V102BatteryProbe.exe in a terminal to verify battery, charging,
firmware, device serial, and MAC information.

V102 LIGHTING AND GAME PROFILES

Right-click the tray icon and choose "V102 RGB och spelprofiler".

Each profile can set:

- Lighting effect, including static palette colors.
- Brightness and effect speed.
- Logo-light color or off.
- One or more game executable paths.

Choose "Gör till bas" for the profile used outside games. The app scans
running processes every two seconds without injecting into games. The
foreground game gets priority, and the base profile is restored when the last
configured game exits.

V102's official protocol controls global lighting zones. It does not expose
an addressable per-key RGB matrix.

PROFILE STORAGE

%LOCALAPPDATA%\MadCatzRat9BatteryTray\v102-profiles-v1.json

PRIVACY

No telemetry, account, or cloud access is used. Battery history is stored at:

%LOCALAPPDATA%\MadCatzRat9BatteryTray\history-v1.txt
%LOCALAPPDATA%\MadCatzRat9BatteryTray\v102-history-v1.txt

TROUBLESHOOTING

If the tray icon is hidden:
Settings > Personalization > Taskbar > Other system tray icons

If the V102 is missing, unplug and reconnect the 2.4 GHz dongle, then run:
V102BatteryProbe.exe
